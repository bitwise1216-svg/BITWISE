# Examples & Reference Inbox

Drop any reference files here:
- **MP4 / Video recordings**: E.g. screen recordings of loading animations, hover effects, page transitions, or cool UI components you saw on other websites.

### How it works:
1. You place your reference file (e.g. `loading-anim.mp4`) in this folder.
2. Tell me: *"I added a loading animation reference in examples, please recreate it"* (or similar).
3. I will inspect the video, recreate the effect with clean code using our animation & design engineering skills, integrate it into the site, and delete the video file once completed.
