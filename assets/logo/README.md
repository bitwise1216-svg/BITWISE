# Official Logo Directory

Place your official logo file in this folder (`assets/logo/`):

### Recommended Setup:
1. Copy your official logo file and paste it into this folder:
   `c:\Users\mruha\Documents\BITWISE\assets\logo\`
2. Name the file **`logo.png`** (or **`logo.svg`** if using vector SVG).

### Supported Formats:
- **PNG** (Recommended for transparent backgrounds): `logo.png`
- **SVG** (Recommended for vector sharpness): `logo.svg`
- **WebP** / **JPG**: `logo.webp` / `logo.jpg`

The website header and favicon are configured to automatically load `assets/logo/logo.png`.
